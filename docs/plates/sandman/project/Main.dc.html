The CLI surface — thirteen verbs
Alpha order, one dispatcher. Each verb is a plain call that takes its roots as arguments and exits; none is a daemon except report serve. Memory verbs read transcripts; machine verbs read the trail.

breathe
The store of the research engine: sources, breaths, passes, reweight. No model, no network.

dream
Short-term → banks: three parallel dreams, 2-of-3 consensus, one commit under the lock.

forget
The privacy ending: every copy of a session destroyed. No archive, no pointer, no routing.

mcp
The stdio tool server: recall, remember and banks for Claude Code and the desktop app.

recall
The surface every session opens on: the directory's bank chain and the recent pointers, 9,000 characters.
machine
reconcile
A revoked event's commits reverted on a reconcile/ branch, repo by repo. Fast-forward trunks only.
memory
reflect
The daily pass: the voyage entry, the log index, bank upkeep. One mind, once a day.
memory
remember
One memory committed now, from inside a session. The in-session path.
owner
report
The night's digest, once per session start; serve is the page on :1705 where proposals get the word.
machine
score
The week's numbers from the trail, shifts, breaths and threads. Worst three first.
machine
shift
The shift engine: clock, pick, brief, handoff. The creation week in New York time; nights only.
memory
take
An ended session archived by move, its pointer dropped. Ten pending pointers fire a dream.
machine
trail
The event log: append, revoke, trailers. Every commit the machine makes names its event.

by hand remember · forget · dream · revoke → reconcile
Exit codes: 0 ran · 1 failed · 2 command line · 3 a runner's fault. Roots come as arguments, never from the environment; $SANDMAN_ROOT moves the whole tree.
