Data root — ~/.sandman
The leading dot is the tier boundary: the hidden directories hold raw bytes the operator's ~/.sandman repo gitignores, the visible ones the content it versions. One gitignorable prefix, since 60 run journals went in with a commit because they shared log/ with the voyage entries (2026-09-05).
