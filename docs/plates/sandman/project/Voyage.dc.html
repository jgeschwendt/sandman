One day, one entry, derived from the banks. The nightly pass hashes what memory recorded that day; only a changed day reaches the mind, and the entry it writes is the first thing every new session reads of what came before.

one entry · never hand-edited
date · day · fingerprint · kind · mind · position · sources · title · written
kind — discovery · milestone · reflection · setback
title — 2–6 words, the way a chapter is named
body — 2–4 sentences of prose; an optional Next: line hands off to the day after
position — stamped, never recomputed: sessions taken, memories landed, live memories, banks
An edit is lost on the next pass that finds the sources changed.
one day at a time
reflect --day <date> renders that one day and nothing else — no drain, sweep or upkeep.
The routine backfills up to three of the last two weeks' days with no entry, newest first.
Idempotent for the day: the entry is a function of the day's sources — same sources, same entry, no model call. A changelog says that something happened, to nobody; the log says what this engine lived through, in one voice.
