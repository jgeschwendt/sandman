The CLI surface — thirteen verbs
Alpha order, one dispatcher. Each verb is a plain call that takes its roots as arguments and exits; none is a daemon except report serve. Memory verbs read transcripts; machine verbs read the trail.
ruachbreatheThe store of the research engine: sources, breaths, passes, reweight. No model, no network.
memorydreamShort-term → banks: three parallel dreams, 2-of-3 consensus, one commit under the lock.
memoryforgetThe privacy ending: every copy of a session destroyed. No archive, no pointer, no routing.
memorymcpThe stdio tool server: recall, remember and banks for Claude Code and the desktop app.
memoryrecallThe surface every session opens on: the directory's bank chain and the recent pointers, 9,000 characters.
machinereconcileA revoked event's commits reverted on a reconcile/ branch, repo by repo. Fast-forward trunks only.
memoryreflectThe daily pass: the voyage entry, the log index, bank upkeep. One mind, once a day.
memoryrememberOne memory committed now, from inside a session. The in-session path.
ownerreportThe night's digest, once per session start; serve is the page on :1705 where proposals get the word.
machinescoreThe week's numbers from the trail, shifts, breaths and threads. Worst three first.
machineshiftThe shift engine: clock, pick, brief, handoff. The creation week in New York time; nights only.
memorytakeAn ended session archived by move, its pointer dropped. Ten pending pointers fire a dream.
machinetrailThe event log: append, revoke, trailers. Every commit the machine makes names its event.

Exit codes: 0 ran · 1 failed · 2 command line · 3 a runner's fault. Roots come as arguments, never from the environment; $SANDMAN_ROOT moves the whole tree.
