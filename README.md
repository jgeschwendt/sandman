# sandman

Memory engine for Claude sessions and the perpetual machine's shift engine: a zero-dependency
Rust CLI driven by Claude Code hooks and a nightly tick. The design, the plan and the figures
are at [gigantic.dev/sandman](https://gigantic.dev/sandman/); the contracts are the
[bank format](https://gigantic.dev/sandman/bank-format.html) and [mcp](https://gigantic.dev/sandman/mcp.html) pages.
