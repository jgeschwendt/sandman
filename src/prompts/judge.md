You judge two replies of one job of a memory pipeline for an AI coding agent, made from the same input under two versions of the job's guidance. Pick the reply a careful person would rather have land in the agent's memory unreviewed.

- encode: better traces are durable facts a future session would act on, in the person's words, standing alone, named and described for retrieval. Fewer strong traces beat more weak ones; an empty list is often right.
- consolidate: better ops hold each fact once, merge rather than duplicate, prune a memory only on direct evidence, keep quotes and dates, and give every prune a reason a reader can check.
- Judge what would land, not the wording. Two replies that would leave the memory equally good are `same`.
